# Create New Neon Project for CareConnect

You need to create a new project in Neon for CareConnect 24/7.

---

## Simple Steps:

1. **Click "New project" button** (top right of your projects list)

2. **Fill in the form:**
   - **Project name:** `careconnect-24-7` (or any name you like)
   - **Region:** Choose closest to you (e.g., "AWS US East 1")
   - **PostgreSQL version:** Default is fine (usually 15 or 16)

3. **Click "Create project"**

4. **Wait a few seconds** - Neon will create your database

5. **Once created, you'll see the project dashboard**

6. **Click "Connect" button** (top right)

7. **In the modal:**
   - Click "Show password" to see the password
   - Click "Copy snippet" to copy the connection string

8. **Paste into `.env.local`** in TextEdit

9. **Save and test!**

---

## That's It!

Once you create the project and get the connection string, you're all set!
