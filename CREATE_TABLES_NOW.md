## Simple Steps:

1. **In Neon dashboard:**
   - Click **"SQL Editor"** (in the left sidebar)

2. **Open `lib/schema.sql`** from this project
   - It's in your project folder: `lib/schema.sql`

3. **Copy ALL the SQL code** from that file

4. **Paste it into Neon SQL Editor**

5. **Click "Run"** (or press Ctrl+Enter / Cmd+Enter)

6. **You should see "Success" or "Query executed successfully"**
